Cause: `Pan.Search.Category.reset_podcasts/1` starts a `Task` per merge/rename (also from the admin grid title edit via `reset_copies` in query_builder.ex) that runs one `UPDATE episodes SET full_text = false WHERE podcast_id = ANY(...)` over the whole category (Sports: 3.78 M rows).
