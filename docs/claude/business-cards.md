Built a print template for Panoptikum business cards, Avery Zweckform C32011(-25) format. Lives outside the Phoenix app repo, in **`/daten/DATA/phoenix/pan-assets/business-cards/`** (a folder the user created specifically for this kind of project asset — check there first for anything similar in future).

**Format, verified against LibreOffice's own label database** (`/usr/lib/libreoffice/share/labels/labels.xml`, entry "32011 Visitenkarten, blanko, schnittgestanzt") rather than trusted from memory: A4 sheet, 2 cols × 5 rows = 10 cards, each 85×54mm, nominal left/right margin 15mm, top/bottom margin 13.5mm, column pitch 95mm (10mm gap between columns), row pitch 54mm (0mm gap between rows). Pre-cut stock ("schnittgestanzt") — no cut marks needed or wanted in the design.

**Deliverables:** `panoptikum_visitenkarten.odp` (editable, one Impress slide per person, 10 identical cards per slide — print a whole sheet per person), `panoptikum_visitenkarten.pdf` (ready-to-print export), `build.py` (regenerates the `.odp` via `odfpy`; edit `add_sheet(...)` calls to change people), `logo.png` (rendered from the site's own source SVG at print quality), `README.md` (points to all of the above, plus the printer-specific corrections below).

**Content:** Stefan Haslinger (Entwickler) / Sonja Waldgruber (Community Managerin) — caught and fixed two likely typos in the user's original input (name "Sonjal"→"Sonja", email domain "panoptkium.social"→"panoptikum.social") by asking rather than silently guessing. Tagline "Podcasts entdecken. Community erleben." replaced the original "Podcast Suchmaschine und Social Network" (user picked from options offered). Card layout: logo + "Panoptikum" wordmark + tagline + "https://panoptikum.social" as one project/brand block up top, name/role/email as a separate person block below it — user explicitly wanted the URL grouped with the project info, above the person data.

**Build technique worth remembering for any future ODF/Impress work:** odfpy `Frame`/`TextBox` elements default to Impress's placeholder styling (blue fill) and can auto-grow past their declared size unless you explicitly give the frame its own `graphic` family `Style` with `fill="none" stroke="none" autogrowheight="false" autogrowwidth="false" padding="0cm"`. Also: never trust hand-calculated print-layout coordinates — render to PDF (`soffice --headless --convert-to pdf`) and rasterize a page (`pdftoppm`) to actually look at it after every layout change; caught real overlap/oversizing bugs this way that would have been invisible from the XML alone.

**Two printer-specific corrections, both from the user's own real-world test prints (not general to the C32011 format, don't reapply if this template is ever reused for a different printer):**
- Whole grid shifted 5mm right (`LEFT0 = 2.0cm` instead of the nominal `1.5cm`) — this printer's feed/registration is offset by that much.
- A bold red "PAPIER EINZELN EINLEGEN" reminder prints in the top margin, above the card grid (never on a cut card) — this printer pulls in two sheets of the thick card stock at once unless fed one at a time.
