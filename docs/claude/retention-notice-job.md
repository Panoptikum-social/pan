It sends one notice to the lowest-id unmarked regular user via `User.next_retention_candidate_id/1` and `User.send_retention_notices/1`. Qualifying users are unverified for more than 30 days, or verified with no login for 2 years (signup date counts if never logged in). Failed ids are skipped in GenServer state until a restart. Deleting stays manual.

**How to apply:** a malformed stored email can crash this job's GenServer (gen_smtp raises instead of erroring on some addresses); since state resets on restart it would retry the same address forever.
