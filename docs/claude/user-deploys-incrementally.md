On 2026-11-05 I kept saying "nothing pushed or deployed yet" during Project #4; the user had deployed at least 5 times during the day and checked each step on prod.

**Why:** the user pushes and deploys themselves; I only see local commits, not what reached prod.
**How to apply:** don't state that commits are unpushed or undeployed. Phrase deploy needs as "what a deploy of these commits needs" (migrations, assets build, console steps), and ask before recording something as deployed or not. Related: [no-amend-after-handoff](no-amend-after-handoff.md).
