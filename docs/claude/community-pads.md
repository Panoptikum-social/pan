**Decisions (2026-10-09, #63–#86):** a "user of the community" = a follower (`follows.community_id`). CodeMirror 6 + `y-codemirror.next` in the browser, `y_ex` (Rust NIF, precompiled) on the server, over a Phoenix Channel, one process per open pad (rejected: Milkdown, a lock, Quill, Yjs on OverType by hand). Split view with server-rendered preview (`markdown/1`), Edit/Preview tabs on mobile, rough scroll sync by percentage. Existing markdown fields stay OverType. Store Yjs state + markdown copy. Several pads per community, title unique per community. Followers read/write, visitors and non-followers see nothing (same "not found" as a missing pad); only that community's moderators who also follow create/rename/delete pads and toggle read only; moderating alone gives no access. Read only freezes for everybody, moderators included. Snapshots markdown only, all kept. Accepted: y_ex is 0.x with one maintainer; an unfollowing user isn't kicked out of an open session; single prod server, no cross-node coordination.

**Step decisions (2026-10-19/20):** #278 slug address `/communities/:id/pads/:slug` (umlauts spelled out, accents dropped, non-Latin kept, renaming breaks old links), #279–#283 (deleting a pad takes snapshots along; community delete cascades in DB; deleted user → snapshots `user_id` NULL), #286–#288 own CodeMirror setup, no autocompletion/lint/markdown language/highlighting (bundle 725→448 kB min, 247→142 kB gzip; nginx gzips /assets on prod), no scroll sync needed on mobile, #289 toolbar (OverType's default buttons/icons minus view mode, plus code block, no shortcuts), #291 selection highlight in the preview via MDEx `sourcepos` (sanitizer keeps `data-sourcepos`).
Defaults chosen by Claude in step 5 and accepted: every follower saves/restores versions; read only blocks restore, not "Save version"; auto snapshots 5 min after the last edit, on last leave and on process stop, skipped if equal to the latest snapshot; manual save always saves; version list in UTC, all versions, no paging; preview throttled to every 300 ms (not a strict debounce). Print prints only the shown version (`pan:print` event in app.js, reusable).

**Code map:** lib/pan_web/models/pad.ex (slugify, permissions/2), pad_snapshot.ex (latest_markdown, list_for), lib/pan_web/pad_server.ex (Yex.DocServer: save 2 s after edit, preview, snapshots, restore, stops 10 s after last viewer), lib/pan_web/channels/{user_socket,pad_channel}.ex, lib/pan_web/live/pad/show.ex, assets/js/pad_editor.js (+ pad_toolbar.js, pad_selection.js) loaded by the PadEditor hook in app.js.
