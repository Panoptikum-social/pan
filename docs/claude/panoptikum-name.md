In texts (docs site, manuals, blog, UI copy) the platform's name is **Panoptikum**, not
"Panoptikum.social". The domain form only appears where it is a link or an address (URLs,
email addresses, `blog.panoptikum.social`, `panoptikum.social/<pid>`).

**Why:** the user finds the domain-as-name strange ("As long as it's not a link, it should be
Panoptikum only"); applied to the whole qed docs site on 2026-11-06, old blog posts included.

**How to apply:** write "Panoptikum" in new text; when touching old text with
"Panoptikum.social" as a name, change it. Related: [jekyll-docs-repo](jekyll-docs-repo.md).
